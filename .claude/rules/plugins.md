# Plugins

No shipped file names a person or a repository other than this one. The awk-using audit scripts run on mawk as well as on the awk of each system. Lint refuses a change under `plugins/<name>/` until that plugin's version is above its last tag, and a version merged to `main` is what an install receives, so work that is not to be released yet stays a draft pull request.
