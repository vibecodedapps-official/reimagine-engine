# Init

1. State the mode.
2. Read `README.md`, package manifests and build files (their scripts and targets), CI workflows, the test layout, the top-level directories, `CONTRIBUTING.md`, and the files under `docs/` with their line counts.
3. Write the root `CLAUDE.md` in the hub shape of `shapes.md`, its sentences drawn from `README.md` and the manifests. Leave it uncommitted and unstaged.
4. Before replying, check the hub against `shapes.md`, its marker, its cap and the paths of its opening paragraph included, and fix any miss.
5. Propose what the repository shows, each placed by `placement.md` and shown in the form of `SKILL.md`, Proposals: a skill for a numbered procedure in `CONTRIBUTING.md` or a runbook under `docs/`, and for a script or build target whose use takes more than one command or a setup step; a nested `CLAUDE.md` for a directory with its own build; a path-scoped rule for a convention of one area. Ask once which to write, by number. Write none without a yes; on a yes, write the ones named, uncommitted. When the repository shows none, say so in one line.
6. End the reply with the hub's path, its line count, that it is uncommitted, and this sentence: `/init` is the host's unopinionated alternative: it writes a `CLAUDE.md` from its own reading of the repository, without the marker or these shapes.
